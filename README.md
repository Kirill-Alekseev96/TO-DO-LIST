# To-Do List

Приложение для управления задачами: добавление, удаление, отметка выполненными, описания и поиск. Данные сохраняются в localStorage.

**[🔗 Демо](https://kirill-alekseev96.github.io/TO-DO-LIST/)**

## 🛠 Стек

- **React 19** — UI
- **Redux Toolkit** — управление состоянием
- **Vite** — сборка
- **CSS** (переменные, БЭМ) — стили

## ✨ Функциональность

- ✅ Добавление задачи
- ✅ Удаление задачи
- ✅ Удаление всех задач
- ✅ Отметка «выполнено»
- ✅ Описание к каждой задаче
- ✅ Поиск по названию
- ✅ Сохранение в localStorage

## 🚀 Запуск локально

```bash
# Клонировать репозиторий
git clone https://github.com/kirill-alekseev96/TO-DO-LIST.git

# Перейти в папку
cd TO-DO-LIST

# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev
